# Inventario de endpoints – FEP.Api

Inventario vivo (lo mantiene el agente `asp-api-migrador`). Antes de crear un endpoint nuevo,
comprueba aquí si ya existe uno reutilizable.

- Base: `/api/v1`. JSON camelCase. Errores como `ProblemDetails` (`application/problem+json`).
- Contenido público: sin autenticación, output cache 5 min (varía por `categoria`, `tipo`, `limite`,
  `federacion`, `provincia`, `busqueda`, `pagina`, `anio`, `genero`, `licencia`)
  y `Cache-Control: public, max-age=300`.
- CORS: orígenes en `Cors:OrigenesPermitidos` (`GET`/`HEAD`; `POST` solo para el chat del asistente).
- Excepción: `/api/v1/licencias` (buscador de licencias, datos personales) no se cachea (`Cache-Control: no-store`) y
  tiene límite de búsquedas por IP (`429`).
- Imágenes: se devuelve el nombre original (`imagen`, `logo`, `archivo`) y la URL absoluta
  (`imagenUrl`, `logoUrl`) calculada con `Media:BaseUrl`.
- OpenAPI (Development): `/openapi/v1.json`.
- Mocks: `src/FEP.Web/wwwroot/mock/<recurso>.json` (misma forma que el DTO; en los mocks
  `imagenUrl`/`logoUrl` apuntan a `assets/img/figma/` para que el prototipo funcione sin backend).
